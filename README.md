# Orbit Calculator

## Objective
A responsive browser calculator for everyday arithmetic, built with HTML5, CSS3, and Vanilla JavaScript.

## Features
- Number and decimal input
- Addition, subtraction, multiplication, and division
- Correct operator precedence
- Clear and backspace controls
- Division-by-zero and invalid-expression messages
- Keyboard support for numbers, operators, Enter, Backspace, and Escape
- Responsive layout for desktop and mobile screens

## Technologies Used
- HTML5
- CSS3 Grid
- Vanilla JavaScript

## Requirements
A modern web browser. No backend, package manager, or installation is required.

## Project Structure
```text
calculator/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run
Open `index.html` directly in a modern browser.

## Example Calculations
- `10 + 5` = `15`
- `8 × 3` = `24`
- `20 ÷ 4` = `5`
- `10 - 7` = `3`
- `5 + 3 × 2` = `11`
- `10 ÷ 0` = `Cannot divide by zero`
